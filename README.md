# MLFF_HFE

**MLFF_HFE** is a toolkit for computing hydration free energies (HFE) of organic molecules using machine-learned force fields (MLFF) with OpenMM.  This workflow was developed by researchers at Schr&ouml;dinger Inc. and reported by Xie *et al.*


## Overview
This package provides scripts and utilities to run hydration free energy calculations using OpenMM and PyTorch-based force fields. The HFE computation follows the procedure described in:

> **Xie, X. et al.** "Accurate Hydration Free Energy Calculations for Diverse Organic Molecules With a Machine Learning Force Field."  
> [ChemRxiv, 2025](https://chemrxiv.org/engage/chemrxiv/article-details/68c48aa423be8e43d6a4015e)
